ML Prediction & MLOps Platform

Compare classifiers, track experiments, serve versioned predictions and inspect feedback-based performance and distribution drift.

scikit-learn / MLflow / FastAPI / Docker

0.996 ROC AUC and 96.5% accuracy on a 114-record holdout.

Evaluation & implementation notes +

569 records → train/validation/test → selection → serving → monitoring

Wisconsin Diagnostic Breast Cancer benchmark with training-only preprocessing and validation-based model selection. Educational use; not a medical diagnostic tool. Docker deployment is supported; no live cloud deployment is claimed.

03Recommendations

Real-Time Recommendation System

Combine offline item similarity with persistent ratings. New feedback changes the next request without batch retraining.

MovieLens / NumPy / FastAPI / SQLite

Recall@10: 6.97% vs 5.66% popularity on 459 relevant holdouts.

Evaluation & implementation notes +

100K ratings → item similarity → user feedback → ranked movies

943 users and 1,682 movies. Full-catalog ranking excludes seen items. Holdouts are chronological within each user, not a global temporal simulation. Local request-time personalization; no distributed streaming infrastructure.
