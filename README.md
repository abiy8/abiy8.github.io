# Abiy Abinet Mamo Portfolio

Static portfolio for https://abiy8.github.io/ featuring five selected projects, a portrait, and downloadable Word/PDF CVs.

## Publish with GitHub Pages

1. Create a public repository named `abiy8.github.io` under account `abiy8`.
2. Upload this folder's contents directly to the repository root on `main`. `index.html` must be at the root, not inside another folder.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
5. Wait for the Pages deployment to finish and visit https://abiy8.github.io/.

The HTML, portrait and CV files are ordinary static assets. No build system, paid hosting or external API credentials are required.

Do not switch existing public profile links until deployment is successful. The included CVs already contain the intended GitHub Pages address.
